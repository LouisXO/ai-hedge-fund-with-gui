## 盘点后的建议顺序

1. **Alpha Vantage `EARNINGS_ESTIMATES`**:免费、带 2017 年起的季度修正,直接做"盈利预测修正"的预注册检验(大盘和全市场各一次)。免费档 25 次/天,拉 600 只大盘约 24 天;可以先用前 100 名做试点。**这可能让付费的 Zacks/EODHD 变得不必要。**
2. **SEC 424B5/S-3 增发 + Form 144**:两个负面事件,预注册成入场否决。
3. **moomoo IV 历史**:每天存 IV/HV,重做期权便宜度门;同时每天存目标价和共识,攒时点数据。
4. **Alpaca 难借券标记**:每天存 `easy_to_borrow`,和 S38 的空头数据合并。
5. **moomoo 期权异动 + 目标价共识**:直接显示在关注名单卡片上(只是展示,不是信号)。
6. **moomoo 价格提醒**:把关注名单的价位同步成 App 推送提醒(只写提醒,不碰交易接口)。

## 原建议顺序(已被上面的盘点取代)

1. 用 Alpaca 竞价接口重做 S27(免费,已验证)。
2. 接 FINRA 空头持仓,预注册"高空头否决"。
3. 订 EODHD €59.99/月,每天存 EPS 趋势和修正次数,攒时点数据;同时向 Zacks/Intrinio 询价,看个人能否买到历史。
4. 其余暂不买。
